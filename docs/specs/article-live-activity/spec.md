# Spec: 아티클 Live Activity

> **무엇을 · 왜.** 아티클을 읽던 사용자가 앱을 벗어나도 현재 읽던 아티클을 Dynamic Island와 Lock Screen에서 다시 확인하고 빠르게 돌아올 수 있게 한다.
> Status: in progress

## 배경 / 문제

현재 아티클 상세 화면을 닫거나 앱을 백그라운드로 보내면 사용자가 읽던 아티클을 다시 찾기 위해 홈 목록을 탐색해야 한다. 기존 `NewdokWidget`은 오늘의 뉴스레터 수를 보여 주는 정적 위젯이라 현재 아티클을 표시하지 않는다.

## 목표 (Goals)

- 아티클 상세 데이터가 준비되면 현재 아티클을 나타내는 Live Activity를 시작한다.
- 아티클을 연 채 앱을 백그라운드로 보내면 활동을 유지한다. 앱 안에서 아티클을 닫거나 다른 화면으로 이동하면 종료한다.
- Dynamic Island와 Lock Screen에 뉴스레터 브랜드 이미지와 현재 아티클을 표시한다. `읽는 중` 고정 문구 대신 작은 상태에는 브랜드명을 한 줄 말줄임으로, 펼친 상태에는 브랜드명과 제목을 표시한다.
- Live Activity를 탭하면 해당 아티클 상세 화면으로 이동한다.
- 다른 아티클을 열면 이전 활동을 종료하고 새 아티클 활동으로 교체한다.
- 로그아웃하면 남아 있는 아티클 활동을 종료한다.

## 비목표 (Non-goals)

- 서버 푸시로 아티클 본문이나 읽기 진행률을 갱신하지 않는다.
- Dynamic Island가 없는 기기에 별도 UI를 추가하지 않는다. 해당 기기에서는 Live Activity가 지원되는 범위에서 Lock Screen에만 표시된다.
- 아티클 본문·개인정보나 읽기 진행률을 Live Activity에 노출하지 않는다.
- 원격 이미지 다운로드가 실패해도 대체 아이콘으로 Live Activity를 표시한다.

## 유저 스토리

- 사용자는 아티클을 읽다가 앱을 나가도 Dynamic Island에서 뉴스레터 브랜드를 확인하고, 펼쳐서 아티클 제목을 보거나 탭 한 번으로 다시 열 수 있다.

## 수용 조건 (Acceptance Criteria)

- [x] 아티클 상세 fetch 성공 후 현재 아티클의 Live Activity가 시작된다.
- [ ] compact에는 브랜드 이미지와 브랜드명 한 줄을 표시하고 긴 브랜드명은 끝을 말줄임한다.
- [ ] minimal에는 브랜드 이미지를 표시하고, expanded와 Lock Screen에는 브랜드명 및 제목 두 줄을 표시한다.
- [ ] 브랜드 이미지는 원본 비율을 유지하며 다운로드 실패 시 대체 아이콘을 표시한다.
- [ ] 진입 경로와 지난 아티클 여부에 관계없이 현재 열린 아티클에서 활동을 시작하고, 아티클 화면을 벗어나면 종료한다.
- [x] Live Activity를 탭하면 `newdok://article/<id>`를 통해 해당 아티클 상세 화면으로 이동한다.
- [x] 다른 아티클을 열면 기존 Live Activity가 중복으로 남지 않는다.
- [x] 로그아웃 시 모든 Newdok 아티클 Live Activity가 즉시 종료된다.
- [x] ActivityKit을 사용할 수 없거나 활동 시작에 실패해도 아티클 읽기 흐름은 중단되지 않는다.
- [x] Detail ViewModel 테스트에서 fetch 성공 시 publisher 호출을 검증한다.
- [ ] 상세 API 요청부터 웹뷰 첫 렌더링 완료까지 로딩 표시가 끊기지 않는다. 재등장 시 상세를 중복 요청하지 않는다.
- [ ] 화면을 닫은 뒤 완료된 요청이 활동을 다시 만들거나 이미 종료한 활동을 갱신하지 않는다.
- [ ] 이미지 포함 attributes와 state의 인코딩 크기를 4KB 미만으로 제한한다.

## 열린 질문

- 지난 아티클의 Live Activity 링크는 지난 아티클 모드를 보존한다. 같은 아티클을 보고 있다면 기존 화면과 스크롤을 유지한다.
