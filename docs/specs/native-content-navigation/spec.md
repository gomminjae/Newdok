# 시스템 검색 진입점과 아티클 툴바

Status: implemented; local tests/build passed; full app UI validation pending — 사용자 요청과 검색 버튼 위치에 대한 정정을 기준으로 한다.

## 요구사항

- 검색 화면의 입력창은 유지한다. 검색 진입 버튼을 시스템 탭바 옆의 분리된 위치로 옮긴다.
- 기존 주요 탭 5개와 아이콘을 유지한다. 마이페이지를 숨기거나 더보기로 임의 이동하지 않는다.
- iOS 27에서는 `TabRole.prominent`와 현재 검색 아이콘을 사용한다. 이전 OS는 기존 검색 진입점을 유지한다.
- 아티클 상단은 시스템 navigation toolbar를 사용하며 뒤로·하이라이트·글자 크기·북마크 아이콘과 동작을 보존한다.
- 검색→뉴스레터→아티클 이동과 목록 문맥, 인증·로그아웃 시 경로 초기화를 유지한다.
